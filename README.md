# MangaVerse

A web-based platform for discovering, organizing, tracking, and discussing manga, manhwa, manhua, light novels, and web novels.

## Project Overview

MangaVerse centralizes different stories and their adaptations into one discovery platform.

## Planned Features

- Story discovery and search
- Multiple editions and formats
- External reading access
- Personal reading library
- Reading progress and history
- Ratings and reviews
- Community discussions
- User authentication
- Administrative content management

## Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MySQL

## Project Status

Currently in the initial setup and development planning phase.
